# Projeto-CN

o programa se baseia em um simulador de erro numerico atravez de truncamento e arredondamento


como usar:
após executar o index, o programa lhe dará opções para que possa escolher entre: soma; subtração; multiplicação; divisão.
depois de escolher a opção, será pedido algumas informações sobre como ajustar os dois números dados ( arredondamento ou truncamento )
ao final do teste, será apresentado o truncamento ou arredondamento, também será apresentado os erros absolutos e relativos da operação desejada
